# 可接受使用政策（Acceptable Use Policy）

**版本**：1.0 ｜ **适用**：Proteus 全部源码、二进制、文档及其任何衍生作品

---

## 1. 为什么要有这份文件

指纹浏览器是一个**双用途**技术。同一套能力，可以用来合规地管理十个跨境电商店铺，也可以用来盗用十万个账号。本项目不能、也不打算假装这个区别不存在。

这份政策是**使用许可的条件**，不是免责声明。违反它，你的 AGPL-3.0 授权自动终止。

---

## 2. 明确允许

| 场景 | 说明 |
|---|---|
| **跨境电商多店铺运营** | 在平台规则允许的范围内管理多个卖家账号 |
| **广告投放与质量检查** | 多地区、多身份的投放验证与素材自查 |
| **QA 与自动化测试** | 在不同设备指纹下测试自有产品的兼容性与行为 |
| **多账号合规管理** | 自有服务的多账号运营（如多租户自测） |
| **隐私研究** | 研究指纹追踪机制、评估追踪器覆盖面 |
| **安全测试** | 在**获得明确授权**的前提下对自有或受托系统做测试 |
| **反爬策略验证** | 作为防守方，验证自己站点的检测能力是否有效 |

判断标准很简单：**你在操作的是你自己的资产，或你有明确授权的东西。**

---

## 3. 明确禁止

| 禁止行为 | 说明 |
|---|---|
| **账号盗用 / 凭证填充** | 使用他人凭证、撞库、接管他人账号 |
| **批量虚假注册** | 绕过平台身份验证批量创建账号 |
| **支付欺诈** | 盗刷、拒付欺诈、洗钱、套现 |
| **促销滥用 / 薅羊毛** | 绕过优惠限制批量套取补贴、返利、空投 |
| **流量造假** | 刷量、点击欺诈、虚假互动、广告作弊 |
| **逃避执法或司法管辖** | 任何以规避法律责任为目的的使用 |
| **绕过访问控制** | 突破他人系统权限、抓取需授权的内容 |
| **骚扰 / 跟踪 / 人肉** | 对特定自然人进行定位、监控、骚扰 |
| **分发恶意软件** | 借浏览器环境传播木马、钓鱼页、挖矿脚本 |
| **DDoS / 资源滥用** | 对目标造成服务不可用 |
| **违反目标站点服务条款** | 即使技术上可行，也不是本项目支持的理由 |

## 4. 关于"我只是想绕过风控"

这是本项目收到最多的诉求，也是最需要说清楚的一条：

**Proteus 提供的是"多环境隔离与指纹自洽"，不是"帮你通过任意风控"。**

如果你的业务模型依赖持续规避某个平台的反滥用机制，那么：
- 本项目**不为此提供任何支持、调优建议或问题解答**
- 你在 issue / discussion 中描述此类用途，会被直接关闭
- 我们不接受"让我通过了 XX 风控"作为贡献或案例

这不是技术洁癖。指纹浏览器这个品类被滥用得足够多，以至于整个生态（托管平台、支付渠道、代码托管、域名注册商）都对这个关键词高度敏感。保护这个项目的可持续性，就是保护它不被用来做那些事。
